---
name: Search Console setup scope
description: The user-selected scope for Google Search Console support in the admin area.
---

Google Search Console support is setup guidance only: domain verification instructions, sitemap submission guidance, and public sitemap/robots links. Do not add OAuth or import Search Console reports unless the user asks.

**Why:** The user selected “Add verification and sitemap setup guidance only.”

**How to apply:** Preserve this boundary when extending the dashboard. Ask before changing the feature to connect a Google account or display search-performance data.
